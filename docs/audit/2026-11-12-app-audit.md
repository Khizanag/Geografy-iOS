# Geografy app audit — 2026-11-12

Whole-app audit of Geografy-iOS at commit `92af07c8`: product scope, architecture, code quality, performance, and shipping readiness. Read-only — no code changed. Items marked **(verified)** were re-checked by hand against the source; the rest come from automated review passes and need a look before acting.

## Verdict

The app is oversized, not broken at the core. 85k lines of Swift, 59 packages, 54 features, and a 31-tile More screen were built in one month (2026-03-20 → 2026-04-20, 907 commits). Polishing all 54 features multiplies the work; shrink to about 15 first, then fix and polish.

## Product and UX

### Information architecture

- **Tabs:** Home, Quiz, Countries, All Maps, More. All Maps is a whole tab for a 7-row launcher.
- **Home:** 8 sections, about 22 tiles, 4 toolbar controls including a coin-store pill.
- **More:** 31 tiles in 5 grids, every one opened as a full-screen cover.
- **Inconsistent presentation:** Countries and Quiz are tabs, yet Home opens them as sheets; Country Detail is a push from the list and a sheet from the spotlight.
- **Home-only features:** 10 features (Map Puzzle, Ocean, Language, Economy, Culture, GeoFeatures, Landmarks, Independence, ContinentStats, World Records) are missing from More, so More's search can't find them.
- **Clashing labels:** "Timeline" vs "Historical Timeline" are different features; "SRS Review" vs "Flashcards".
- **Three searches:** Home toolbar, More tile, Countries list.

### Unreachable or stub

LandmarkQuiz, MapColoring, SizeVisualization, Onboarding (never imported), Themes (`ComingSoonView`), Collections viewer (items can be saved but never viewed), the Home section editor (would crash — its service is never injected), and `FeatureFlagService` (33 flags, applied nowhere).

### Conflicts with project rules

- **Monetization before a decision:** StoreKit 2 products (`premium.monthly/annual/lifetime`, five coin packs), a paywall reached from 6 screens, and `isPremium` gating in 16 files. No products exist, so gated content is permanently locked in Release. Locked-section copy promises an "ad-free experience".
- **Auth:** Apple, Google, and guest; no email/password. Google `clientID` is a placeholder (`GoogleSignInHandler.swift:46`, **verified**). No backend, so sign-in only switches local data.
- **Offline:** Currency converter (`open.er-api.com`) is empty on a first offline launch; organization logos load through `AsyncImage` and are blank offline.

### Recommended scope

Core loop: browse a country, see it on the map, quiz yourself, review with spaced repetition, return for the daily challenge. Tabs: Explore (map + list), Play, Learn, Profile.

## Map

The map is the strongest candidate for investment and stays inside this repo as a `Map` module.

- **Rendering:** `MapCanvasView` fills all 548,471 vertices in 4,274 polygons on every gesture frame, up to three times for horizontal wrapping, with only bounding-box culling. Labels resolve `Text` twice per country per copy per frame.
- **Loading:** first open decodes the 13 MB `countries.geojson` into nested `[Double]` arrays; failure silently yields an empty map.
- **Duplication:** Map, OrganizationMap, HistoricalMap, and TravelMap each copy `clampVerticalOffset`, `wrapHorizontalOffset`, `computeMinScale`, and `computeContentBounds`.
- **Fix direction:** pre-simplify 2–3 levels of detail at build time into a binary format, pick by scale, cache resolved labels, extract one `MapViewport` model, fix wrapped taps and holes.
