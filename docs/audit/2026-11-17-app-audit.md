# Geografy app audit — 2026-11-17

A second whole-app audit, five days after the [2026-11-12 audit](2026-11-12-app-audit.md) whose plan has landed. Four read-only reviews ran in parallel (design consistency, performance, code health, product), and the headline findings were spot-checked by hand. Paths are shortened; each package's sources live under `Sources/<Package>/`.

## Verdict

The structure is sound now: four tabs, eleven packages, routes, a cached map, lazy lists. What holds the app back is in three places:

1. **Things that look done but don't work**: quit confirmations, a third of the achievements, the Profile "explored" stat, sound effects.
2. **The same job done several ways**: seven game result screens, two country rows, eleven stat views, green and red used as decoration.
3. **A learning loop that doesn't reward learning**: the streak counts app opens, and most games award no XP.

Fixing those three makes the app feel finished before anything new is added.

**Status:** phases 1–4 are done (2026-11-17). Phase 5 is next. Left from phase 4, each needing a measurement or a migration first:

- `#Index` on `userID`: the versioned schemas point at the live models, so it needs a frozen model, a new schema version, and a stage.
- List-size flag assets: decoding moved off launch; shipping a second set of 256 images waits for a profile showing it's needed.
- Explore's segments still rebuild a page on switch: keeping both alive would keep the hidden page's toolbar items in the bar.
- `MapFrame.overscan` stays 0.5: taps no longer redraw the base map, and a smaller value redraws more often during pans.

Phases 1 and 2 are first because users feel them directly and they're small. Phase 5's quiz session model should land before phase 6, which builds on it.

## 2. Reward learning

- **XP for every game.** Daily Challenge, Pin Drop, Map Puzzle, Flashcards, Learning Path, and Word Search award none. Marking 197 countries visited jumps to level 6. Add XP sources for each game and cap travel XP.
- **One streak that means "learned today".** Three streaks disagree: app-open (`StreakService:35`, shown on Profile, the widget, Game Center), Daily Challenge, and flashcards. Count a day when a challenge, quiz, or review is done, and show that one everywhere.
- **Reminders that help.** They fire even after you've played, a tap doesn't open the challenge, and the copy promises three challenge types when there is one a day (`NotificationService:49,67`). Skip when `hasPlayedToday`, deep-link the tap, fix the copy.
- **A sane due count.** A new user sees "197 flashcards due" because unseen cards count as due (`FlashcardService:80`). Count seen cards plus about ten new a day.

## 3. Consistency

1. **Color meaning.** Eight hub tiles are green and four red (`HubItem:138-168`); Speed Run and Multiplayer use the error color as their game color, so their whole UI turns red; `IconBadge`, `StatTile`, `ResultStatItem`, `ShareBar`, and `PulsingCirclesView` default to the accent green. Add category colors, make shared defaults neutral, keep green for success and red for errors and deletes. There are also two reds (`destructive` and `error`); keep one.
2. **One game result screen.** Seven result screens build stats seven ways, use four hero styles and four title weights, and disagree on Done vs Close and the replay icon. Extract a shared result view (hero, `StatTileRow`, XP badge, `ButtonRow`) with Pin Drop's stats and the quiz's bottom bar as the reference.
3. **One way to leave a game.** See phase 1; pause buttons are bare images instead of toolbar labels (`QuizSessionScreen:107-117`, `WordSearchGameScreen:62-71`).
4. **Settings-style rows everywhere settings appear.** Move Settings' row components to the design system; align `ProfileScreen+Account` (material card per row, Sign Out unconfirmed), `StorageScreen`, and `TerritorialDisputesScreen`. Give `GlassButton` a destructive role and make Sign Out red.
5. **One country row.** `CountryRowView` (main list, Favorites, Bucket List) vs `CountryListRow` wrapped in its own card in seven screens. Use one row inside `RowListCard`, as Compare and Distance do.
6. **One stat component.** `ResultStatItem` (16 uses, unlocalized `String` labels) vs `StatTile` (36) plus nine private stat views.
7. **Shared pieces built twice.** `RegionPicker` rebuilt in Pin Drop and Map Puzzle setup; four text-field styles (add a `FormField`); hand-made bars where `ShareBar` fits; the journal photo viewer instead of `.zoomableViewer`; segmented pickers under the nav bar in World Facts and Time Zones instead of `.segmentedTabs`; raw `Picker`s in the multiplayer lobby instead of `OptionPickerRow`.
8. **Liquid Glass.** `.ultraThinMaterial` cards in Leaderboards, Profile, Edit Profile, and the lobby should be `CardView`; floating banners and map overlays should be glass; Pin Drop results put glass on glass; only 3 of about 20 bottom-bar screens set the scroll edge effect; save buttons are plain or green text instead of the confirmation checkmark.
9. **Tokens.** 103 raw `.opacity(0.x)` values in 12 variants (add opacity tokens), 42 literal spacings of 2–3 points (add a token below `xxs`), 16 literal corner radii, hard-coded divider insets, raw `.white`/`.black` in Pin Drop.
10. **Accessibility.** The achievement banner and several animations ignore Reduce Motion; fixed frames around text in Achievements, Phrasebook, and the timeline slider; 36-point tap targets in Timeline.
11. **Empty states.** Mixed `ContentUnavailableView` and `EmptyStateView`; "Try World" dead ends without a button in Quiz and Map Puzzle.

## 4. Smoothness

1. **Travel, Organization, and Historical maps redraw the whole world on every gesture frame.** They pass scale and offset straight to the canvas instead of using `MapViewport` like the main map (`TravelMapScreen:244-290`, `OrganizationMapScreen:100-290`, `HistoricalMapCanvas:13`). This is the pan stutter the main map already fixed.
2. **A tap on the main map redraws a canvas four times the screen.** Selection and the capital pin are part of the base canvas's equality (`MapCanvasView:136,310`), with `overscan = 0.5` (`MapState:178`). Draw them in an overlay; try a smaller overscan.
3. **Map coloring on the main thread at launch.** An O(n²) DSatur loop with about 30k allocations (`MapColoringEngine:29,69`, called from `GeoJSONCache:62`). Move it into the parse task and cache it per palette.
4. **Labels re-laid out every gesture frame** (`MapLabelPainter:63`). Skip during gestures or cache by font step.
5. **Every flag decoded at launch.** 256 PNGs at 1280×960 (12 MB) prewarmed from `ContentView:66`. Ship list-size flags and prewarm when Explore first appears.
6. **First map tap sets up audio on the main thread** (`SoundService:32-35`), and the speech synthesizer is built at launch. Moot if sound is removed; otherwise preload in the background.
7. **Search folds about 650 strings per keystroke** (`SearchEngine:118-131`); `CountryPicker.sections` is computed twice per render.
8. **Growing launch fetches.** Total XP is summed from every record ever earned (`XPService:64`); no `#Index` on `userID`. Store the total; add indexes.
9. **Smaller items.** Explore's segments rebuild the whole list on switch (`SegmentedTabs:73`); every projection's outlines stay in memory (`GeoJSONCache:21`); forever-pulsing level badge and population ticker; achievement progress saved twelve times per quiz.

Measure 2, 3, 5, and 8 in Instruments; their cost is estimated from code.

## 5. Clean code

1. **Dead code.** About 900 lines of unused design-system components (`ComingSoonView`, `GeoButton`, `MetalAmbientView` and its shader, `NumericTicker`, skeleton compositions, `SymbolEffectLibrary`, `AdaptiveGrid`, unused font tokens); the Lottie dependency with no animations; `SpellingBeeGuide`, `FlashcardDeckCard`; the unused `GameCenterService.AchievementID`; the unobserved Mac "Random Country" menu item; 13 test-checklist keys for cut features (and the checklist ships in Release); empty folders left by cut features.
2. **About 7,100 lines of data written as Swift.** `FlagSymbolismData` (1,210) and `CountryFunFacts` (935) break the 800-line limit; 15 `swiftlint:disable` lines exist to allow them. Move them to bundled JSON like `country_profiles.json`.
3. **Game logic in views.** `QuizSessionScreen` and its extensions: 786 lines and 27 `@State`, untestable. XP rules spread over four views; answer feedback written four times; `asyncAfter` races left in eight places. Add a `QuizSession` model, one `XPRules`, and one cancellable feedback helper.
4. **Persistence.** 18 silent `try? save()` calls, ten in `AuthService` including guest migration and deletion; about 12 hand-written Codable-in-UserDefaults blocks; "recent pairs" built four times; two store-opening paths; the widget contract (app group, keys, model) defined on both sides. Add a logged save, a defaults helper, a generic `RecentList`, a container factory, and one widget contract file.
5. **Architecture drift.** Feature-Travel depends on Feature-Country and Feature-Map without using them; Core-Service keeps an unused Core-Navigation dependency; seven services created inside views instead of `AppDependencies`; `navigationDestination` and inline covers that bypass routes; a five-name NotificationCenter bus for tab switching.
6. **Concurrency.** `PronunciationService:273-275` (`@unchecked Sendable` with `nonisolated(unsafe)` closures) is a possible race; several other unsafe annotations can simply go.
7. **Tests.** Feature-Map has no test target; the riskiest untested logic is `AuthService` (migration, deletion), `StreakService`, XP rules, the quiz session, and `LearningPathService`.
8. **Oversized files.** `SettingsScreen` 596, `SpeedRunSessionScreen` 491, `MapScreen` 487, `WordSearchGameScreen` 482, `PinDropScreen` 474.
9. **Stale docs.** `.instructions/geografy-ios.md` still describes five tabs, 55 features, StoreKit, and coins; rewrite it from `architecture.md`. Delete `IMPROVEMENT_PLAN.md`, `MODULARIZATION_PLAN.md`, and `.instructions/navigation-refactor.md`; cut `TODO.md` and `LAUNCH_PLAN.md` to what's still open.

## 6. New features

Ranked by value for effort; each reuses what the app already has.

1. **Mastery across all games (L).** Every game records per-country right and wrong answers into the flashcard SM-2 store, so the games become one curriculum. Quiz results gain "add misses to review" and a review of missed answers.
2. **"Name the highlighted country" map quiz (M–L).** The most geographic mode missing (it's in `TODO.md`). Reuses the map's highlight and selection, the question generator, and the quiz session. Add "Play this continent" from the Map tab and continent overview, which today lead nowhere.
3. **Mastery map and continent progress (M, after 1).** A palette coloring countries by mastery and a progress ring per continent; continent achievements unlock on mastery.
4. **Real Learning Path lessons (M).** 12 of 36 lessons are a line of text and "Mark as Complete" (`LessonScreen:56-72`). Make quiz lessons start a scoped quiz that passes at 80%.
5. **First-run flow (M).** Home country (marks it visited, focuses the map), goals, optional reminder, then the first Daily Challenge on the Play tab. There is no onboarding today.
6. **Deep links, widgets, and sharing (M).** `geografy://country/{code}` and `geografy://daily`; the Country of the Day widget opens that country; one share card for quiz, Pin Drop, and Speed Run results.
